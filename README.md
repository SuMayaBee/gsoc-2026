# GSoC 2026: Panel Live Server

Sumaiya Islam's final work product for Google Summer of Code 2026 with NumFOCUS (HoloViz).

The site summarises 32 merged GSoC contributions: 31 merged pull requests in Panel Live Server and one HoloViz blog contribution. It includes the screenshot-review workflow, major technical work, a contribution record, and links to the full report and upstream code.

The published site is intended to be served with GitHub Pages.
